# WIL & YAT — Front matter (prefaces)

OCR transcription, with Russian translations, of the **front matter** (title pages and prefaces) of the two dictionaries compared in this repository — both part of the [Cologne Digital Sanskrit Lexicon](https://www.sanskrit-lexicon.uni-koeln.de/) (CDSL):

> **WIL** — H. H. Wilson, *A Dictionary in Sanscrit and English*, 2nd edition, Calcutta, Education Press, 1832.
>
> **YAT** — W. Yates, *A Dictionary in Sanscrit and English, designed for the use of private students and of Indian colleges and schools*, Calcutta, Baptist Mission Press, 1846. (Printing was completed after the author's death by J. Wenger.)

- **Source language:** English for both. Because the source is already English, there is **no `.en.md`** per-page file; the source page *is* the English text. Russian translations are supplied as `.ru.md`.
- **Source scans:** Cologne csldoc — [WIL front-matter index](https://sanskrit-lexicon.uni-koeln.de/scans/csldev/csldoc/build/dictionaries/prefaces/wilpref.html), [YAT front-matter index](https://sanskrit-lexicon.uni-koeln.de/scans/csldev/csldoc/build/dictionaries/prefaces/yatpref.html).
- The original spelling is preserved verbatim (e.g. *Sanscrit*, *knowlege*, *shew*, *superintendance*).
- Yates's preface explicitly frames his work as a portable, cheaper octavo reduction of Wilson's quarto — the textual basis for the headword comparison done elsewhere in this repo.

## File conventions

| Suffix | Content |
|---|---|
| `wilNN.md` / `yatNN.md` | Faithful English transcription of page NN (this *is* the source) |

```sh
DICT=wil python build_combined.py
DICT=yat python build_combined.py
```
